# R27U91：PR #1 的 A/B/C 实机测试结果

测试日期：2026-10-07。显示器：R27U91，EDID vendor=20588、product=9988；Apple Silicon Mac，USB-C 连接。

测试对象：[PR #1](https://github.com/titi14gj/MacMix/pull/1)，提交 `3236480c60be7622c09be9f83630f1bed9f224b6`。
独立应用名称为 MacMix PR1 Test，应用标识 `jazmin.MacMix.PR1Test`，版本 2.2.1（20.2）。仅本地包装改为独立应用名称/标识并关闭自动更新，DDC 和 AudioModel 使用该提交代码。正式版退出后测试；每次切换模式均退出并重新启动测试版。

作者的 DDC 回归测试通过，Apple Silicon Debug 完整构建成功，产物通过 `codesign --verify --deep --strict`。以下声音和 OSD 变化由测试者实际确认，读取值来自独立只读 DDC 工具。

## 对照结果

| 模式 | SendMuteCommands | InvertMuteValues | 实测结果 |
| --- | --- | --- | --- |
| A：只写音量 | false | false | 滑块、OSD 一致且有声；静音及恢复正常；调节平滑 |
| B：标准静音值 | true | false | 启动有声，拖动后无声；静音/取消静音后声音也未恢复 |
| C：反转静音值 | true | true | 音量及静音恢复正常；拖动不平滑、疑似爆音 |

表中键全名为 `MacMixDDCU9SendMuteCommands`、`MacMixDDCU9InvertMuteValues`。

## 模式 A

- 固定在 11% 时，滑块、OSD 与 DDC current=11 一致，声音正常。
- 静音后 OSD=0，声音消失；取消静音后 OSD=11，声音恢复。
- 滑块从 0 回到 11%：OSD 跟随，声音恢复。
- 取消静音后读取：0x62 current=11、maximum=65535；0x8D current=1。
- 完成 B/C 后切回 A，用同一段音频、相同拖动方式比较，测试者确认 A 很平滑。

## 模式 B

启动前 0x62 current=51、0x8D current=1，测试者确认默认有声。

- 拖动后滑块和 OSD 均为 16，但无声。
- 此时读取 0x62 current=16、maximum=65535；0x8D current=0。
- 点击静音：OSD=0，无声。
- 取消静音：OSD=16，仍无声；读取仍为 0x62=16、0x8D=0。

根据该提交代码，模式 B 非零音量写入成功后发送 `0x8D=2`。本测试应用未增加完整发送包日志，这个发送值根据源码路径及设置判断；表中的读取响应则为实际读取。

## 模式 C

为清除 B 遗留的静音，在退出测试版后用独立工具仅写入 `0x8D=1`；未修改音量。写入 I/O 成功，读回 0x62=16、0x8D=1。随后启动 C，测试者确认默认有声。

- 10%：有声，OSD=10；读取 0x62 current=10、maximum=65535，0x8D current=1。
- 30%、50%：均有声，OSD 与滑块一致。两档未分别保持后读取，数值一致性为测试者确认。
- 静音：声音消失，OSD=0。取消静音：声音及原音量恢复。
- 拖动滑块时声音不平滑，测试者描述为“疑似音爆”。未录音或测量波形，不能作为已测量的爆音结论。
- 切回 A 前读到 0x62 current=35、0x8D current=1，此时已继续调节，不能用该样本验证此前的 30%/50%。

## 关键原始响应

| 状态 | 0x62 响应 | 0x8D 响应 |
| --- | --- | --- |
| A 取消静音后，11% | `6E 88 02 00 62 01 FF FF 00 0B DC` | `6E 88 02 00 8D 01 FF FF 00 01 39` |
| B 拖动后/取消静音后，16% | `6E 88 02 00 62 01 FF FF 00 10 C7` | `6E 88 02 00 8D 01 FF FF 00 00 38` |
| C 保持 10% | `6E 88 02 00 62 01 FF FF 00 0A DD` | `6E 88 02 00 8D 01 FF FF 00 01 39` |

上述读取 I/O 均成功。静音按钮按下期间未独立读取 DDC，OSD=0 与声音消失为测试者确认。

## 建议及验证边界

此显示器优先保留默认模式 A。B 无声、C 正常支持对本显示器使用反转静音值的兼容性判断，但 C 调节连续性不如 A。

源码在每次非零音量写入成功后调用 `applyMute(false)`；B/C 随之发送 0x8D，A 对 R27U91 跳过。额外静音指令可能与调节不平滑有关；尚未隔离发送频率或测量音频，具体机制未确认。

未覆盖所有音量点、重新连接或系统重启；未单独测试 C 的滑块 0→非零路径。本次结果限于这台显示器。原始本地日志未上传，本文包含整理后的读数与硬件观察。
